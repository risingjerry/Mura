# Demo GIF generator

`docs/demo.gif` is a rendered illustration, not a screen recording. It reuses the real screenshot `docs/images/mura-editor.png` (parts of the canvas are hidden, then revealed) and shows real `dmwctl` commands from `skills/mura/SKILL.md`. No real wallpaper is changed.

Rebuild (needs Google Chrome, ffmpeg, optionally gifsicle):

```bash
python3 docs/demo/build.py
```
